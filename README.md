# Lounge with DANG 🎲✨

A cozy, intimate real-time multiplayer tabletop board game lounge with WebRTC voice chat, tactile 3D dice physics, and physical stone tracks.

## Features
- **Intimate Mélange Tabletop Lounge**: Warm heathered slate palette with candlelit wine/rose ambient undertones.
- **Real-Time Multiplayer**: Built with Node.js & Socket.io for rock-solid zero-latency multiplayer.
- **Integrated WebRTC Voice Chat**: Live voice chat with spatial audio waveform indicators.
- **Tactile 3D Dice**: Three.js porcelain dice with royal crimson pips and realistic roll physics.
- **Smart Game Engine**:
  - **Quick Match (2 Goals)** vs **Classic (4 Goals)**
  - **Defensive Wall Blockades**
  - **Network Auto-Pilot Disconnect Proxy**
  - **Smart Auto-Move** for opening sixes and single choices.
- **AAA Procedural Audio**: Sub-bass knockout stomp, tumbling dice clatter, and ascending pentatonic step-hops.

## 1-Click Deploy on Render (100% Free)
1. Fork or push this repository to GitHub.
2. Log into [Render.com](https://render.com) (free).
3. Create a **New Web Service** pointing to this repo.
4. Render will automatically detect the included `render.yaml` configuration:
   - **Runtime**: Node
   - **Build Command**: `npm install`
   - **Start Command**: `node server.js`
   - **Plan**: Free
